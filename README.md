# Sistema Saludador

Maqueta de escritorio en JavaFX.

## Cómo ejecutar (Windows)

Requisito: Java 25 o superior (`java -version`).

En la carpeta del proyecto:

```bat
ejecutar.bat
```

O:

```bat
mvnw.cmd javafx:run
```

La primera vez Maven Wrapper descarga las dependencias; puede tardar unos minutos.
